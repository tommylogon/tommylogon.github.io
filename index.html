01 · SIMULATION · AI AGENTS · ARCHITECTURE

VirtualWorld

A local, cloud-free world simulation engine for persistent AI agents in graph-based worlds. The central architectural rule is simple: the world is authoritative; the LLM is a participant. Features an append-only SQLite event stream with timeline branching, a low-cost Backsim layer for off-screen characters, an Emotion Matrix, an attention reranker, an E2E benchmark suite, and 60+ MCP tools.

Separate cognition from time.

The world can advance cheaply while expensive reasoning is reserved for characters that need it.

Keep identity continuous.

A character moving between background simulation and foreground interaction remains the same character with the same state.

Build reusable primitives.

Small composable mechanisms are more valuable than one-off features.

04 / Approach
“I don't just want to make it work. I want to understand why it works.”

My strongest work tends to happen where the problem is only partially understood. I break a large problem into smaller questions, test assumptions, trace failures, and build the solution around a coherent model of the system.

That means I am comfortable moving between abstraction levels: customer problem, product behaviour, API contract, database state, implementation details and tests.
