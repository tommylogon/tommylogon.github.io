# Tommy Slaatbraaten — Portfolio

A static HTML/CSS/JavaScript portfolio. No build step or backend is required.

## Preview locally
Open `index.html` in a browser.

## Deploy
You can publish these files using GitHub Pages, Cloudflare Pages, or Azure Static Web Apps. See the hosting notes provided with the project.

## Before publishing
- Verify that the Everspring/PayEx date split and role descriptions are accurate.
- Check the LinkedIn URL and project links.
- Consider whether you want your email address published; this version uses public profile links only.
- All project metrics are dated snapshots and should be refreshed when they change.
